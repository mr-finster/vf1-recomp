What's new over the arcade

  • Straight to the game. No boot screens or credits, always free play.
  • 3D upscaled up to 6x, the original low-poly look kept crisp.
  • Widescreen and ultrawide. The stages and skies really extend to the sides.
  • Animation up to 120 fps.
  • Antialiasing, and scanline or CRT screen filters.
  • An options menu for display, sound (music and effects apart), controls and the arcade's own settings: difficulty, ring size, rounds to win and continues. No test mode needed.
  • Long-standing MAME glitches fixed: skies, floors and shadows checked against real cabinets.
  • Secret characters: fighters cut from the arcade ROM (Siba, Jeff, Takeru and the Koskol brothers) and Dural, playable from the Cheats menu, with select portraits and icons made to match.
  • Cheats: infinite energy, one-hit KO, no time limit, tiny or huge rings.
  • Keyboard or controller, two players. Every button remappable, and the menu on any pad (L3 + R3, or the touchpad).

You need

MAME's "vf" set, as vf.zip, including 315-5724.bin (the TGP chip's program). Newer MAME sets have it; older ones don't, and without it the fighters' hair goes wrong, so the game asks for a set that has it.

Nothing from the game is included or shared. Each file is checked by CRC, and the code is recompiled on your machine when it starts.

Where it goes

Mac and Windows: it asks for it the first time and keeps a copy.

Steam Deck: put it in VirtuaFighter/roms.

Windows 10 or 11 (64-bit)

  1. Unzip the VirtuaFighter folder anywhere.
  2. Run VirtuaFighter.exe. It isn't signed, so SmartScreen may warn: More info > Run anyway.
  3. Choose your vf.zip when it asks.

Mac (macOS 11+, Apple silicon or Intel)

  1. Unzip and move Virtua Fighter Recomp to Applications.
  2. It isn't signed, so macOS blocks it the first time. Open it once, close the message, then System Settings > Privacy & Security > Open Anyway.
  3. Choose your vf.zip when it asks.

Steam Deck

  1. Copy the download to the Deck and unpack it there (Desktop Mode: right-click > Extract > Extract archive here).
  2. Put vf.zip in VirtuaFighter/roms.
  3. Desktop Mode: Steam > Add a Non-Steam Game, pick the vf file (file type: All files). In its Properties, set Start In to the VirtuaFighter folder and turn off any forced compatibility tool (Proton).
  4. Play it from Game Mode with the default gamepad layout.

Portable: a file named portable.txt next to the program (Mac: next to the app) keeps everything in its folder, the copy of vf.zip too, and nothing in your user data folder.

Your own ROM folder (e.g. Batocera's /userdata/roms/ports/vf): start it with --roms <folder>, set VF_ROMS, or add roms_folder = <folder> to settings.ini. The game looks for vf.zip there first and only reads it; log.txt says which folder it used. See the README.

A fan-made static recompilation of Virtua Fighter (Sega Model 1, 1993): the arcade's own code is translated to native code on your machine, and the rest of the board is rebuilt around it. No ROMs or game files are included: you need your own copy. Not affiliated with or endorsed by SEGA. Unsigned: run it at your own risk.

Made with the help of AI coding tools. Every build is checked frame by frame against the arcade (via MAME).
